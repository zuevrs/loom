# v5 migration pilot

Run `bash scripts/v5-migration-pilot`. The script creates only disposable local repositories and no hosted or real-remote effects. It executes native Git branches, worktrees, commits, ordinary merges, ancestry-preserving cleanup, and confirmed unversioned setup. It invokes the executable continuation, scoped-knowledge, coordinator-only, Finish-boundary, reconciliation, and Tend archive planners. `GRILL_STOP`, `RECONCILIATION_PREVIEW`, `ARCHIVE_PREVIEW`, and `DONE` are planner results, not claims that Git understands semantic conflicts.

The fixture has one Git-backed owner, Alpha and Beta writable owner worktrees, isolated catalog/notifications lanes for both Stories, and one scoped shared contract. Finish commits remain local while local bare service remotes retain only baseline `main`. Product branches are merged into canonical service `main` before owner Tend. Beta's textually mergeable but semantically incompatible proposal produces planner `GRILL_STOP`; the pilot then supplies an explicit conflict-free inventory and records the reconciled contract in an observed ordinary owner merge. The Beta MANIFEST binds the exact reconciliation owner commit/tree and service merge refs, plus required `CONTEXT.md` and `docs/adr/0001-order-events.md` paths with SHA-256 digests and is accepted by executable Tend before and after the archive commit. Archive commits precede exact clean/inactive service-lane cleanup. A second owner explicitly chooses degraded unversioned mode.
