# Maintainer behavioral evals

This directory is not package content. Run `node tooling/evals/smoke.mjs --tier quick --dry-run` to inspect the deterministic nine-case plan. Raw runs belong under `.loom/evals/raw/` and are redacted before persistence; no command runs a model without an explicit non-dry-run invocation.

Tiers are `quick` (9x1), `release` (six contract cases once, three frontier cases three times), and `full` (9x3). Baseline defaults to immutable tag `v7.11.0`; dirty candidate probes require explicit advisory mode. OMP is pinned to 17.2.7 with generator `claude-opus-5` and blind judge `gpt-5.6-sol`; the maintainer CLI accepts only exact `omp/17.2.7` or `omp v17.2.7` output (surrounding whitespace only) and verifies semantic equality and parses the JSONL event stream, requiring a complete terminal assistant response with the requested model before safety or judge parsing.

Runs use a deterministic `runId` over immutable arm identities, tier, pins, rubric, timeout, registry, and dirty-probe state (tracked binary diff plus deterministic untracked names, file types/modes, and bytes), so an unchanged rerun resumes without calls. The CLI always derives this identity and rejects unknown options, including the legacy `--run-id` override. Compact summaries report baseline and candidate safety and advisory quality separately plus candidate-minus-baseline quality delta; transport blockers suppress quality.


The shared `rows.jsonl` file is a compatibility contract. Each read derives the exact generator and judge identities from the active run's selected-tier manifest, then admits only strict current-schema rows with canonical identities and judge keys. Malformed, legacy, foreign-run, out-of-manifest, and forged-key rows are ignored. If more than one persisted row claims a canonical identity, all persisted rows for that identity are ignored and the identity is rerun; none can affect resume, scoring, aggregation, summary, or BLOCKED state. A strict judge result with `blocker: true` is complete and resumable, makes the outcome `BLOCKED`, and suppresses both quality values. The dirty digest covers the tracked binary diff plus Git-surfaced, non-ignored untracked regular files and symlinks. Unsupported types fail only when Git surfaces that entry; arbitrary filesystem objects Git excludes are outside candidate identity.

OMP execution uses an explicit executable-closure policy: resolve and validate the absolute OMP executable, probe it under only its directory plus fixed system directories, and if that closed probe fails, resolve and validate absolute executable `bun` once via `/usr/bin/which` using the invoking PATH. Only `dirname(bun)` is then added; unrelated invoking-PATH directories are never inherited. A self-contained OMP needs no runtime addition, while an unavailable or invalid required bun prerequisite fails closed with probe evidence.

All raw evidence crosses the shared `tooling/shared.mjs` redaction boundary before persistence. It preserves structured JSON while recursively redacting secret-bearing keys, credential headers and assignments, URL userinfo, and explicit local path forms.
